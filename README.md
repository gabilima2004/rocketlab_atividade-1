# Atividade 1 — Rocket lab

Atividade prática desenvolvida no **Databricks** utilizando **PySpark**.

### Conteúdo

- Leitura e manipulação de dados de jogadores do FIFA Ultimate Team
- Filtragem e classificação de jogadores
- Uso de `join`, `groupBy` e funções condicionais
- Construção do **Dream Team do Brasil (4-4-2)**
- Desafio bônus com remoção de versões duplicadas dos jogadores

O código foi desenvolvido originalmente no Databricks e posteriormente adicionado a este repositório para compartilhamento.
